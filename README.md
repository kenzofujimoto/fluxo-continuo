# MobiMatch Alpha

Matriz pública independente de equivalências curriculares para mobilidade internacional no campus Mackenzie Alphaville.

Site: https://mobimatch-alpha.vercel.app

## Escopo
- Quatro cursos: Ciência da Computação, Sistemas de Informação, Direito e Administração.
- Planilha COI 1S/2027: 66 universidades; campos de curso e idioma separados por instituição.
- Comparações de ementa somente com documentos consultados; nenhuma equivalência homologada.
- Página de idiomas com preços, fontes e benefícios MLC/GCUB.

**Projeto de estudante não oficial.** Consulte sempre a COI e a coordenação para regras vigentes. O código-fonte e os dados completos serão adicionados em commits próprios.
