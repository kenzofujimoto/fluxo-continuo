# Country flags

Local 4:3 SVG assets copied without modification from flag-icons 7.6.0 (MIT), https://github.com/lipis/flag-icons. Full license: LICENSE. No runtime CDN requests.

CountryFlag displays the source geometry through an SVG luminance/discrete filter in the MackJr red/cream palette. These are decorative brand adaptations, not color-accurate national flags; country names remain visible beside them.
